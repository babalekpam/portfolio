Watching the Wire

Authorization and egress gateway for AI agents

Status: pilot-ready gateway and reproducible benchmark
Code review available under NDA

An AI agent hijacked by prompt injection still looks like a legitimate client to the network. This gateway ties every outbound connection to the task the agent was actually given, and denies the rest. Sized for large enterprise networks.

  • Signed, expiring task plans and delegation chains, so each connection traces back to a declared task and an accountable owner
  • Default-deny egress proxy with TLS interception that flags or blocks traffic the plan does not justify
  • Tamper-evident flight recorder, a human approval service, and a monitor mode for pilots
  • Benchmark testing whether agent hijacking can be detected from network traffic alone, with no model internals, prompt inspection or agent cooperation, including the cases where the wire-level signal fails

ADRESA

National digital addressing system for West Africa

Status: working implementation
Pilot country Togo, pilot city Lomé

Gives every building an official, verifiable address in countries where most streets have no names.

  • Three-layer model: an immutable geocode per building, a mutable person-to-place pointer, and a confidence score
  • Citizen registration, official identity verification, then address and registry number assignment
  • Public verification endpoint that confirms an address without ever exposing identity data
  • Partner API for geocoding, reverse lookup and autocomplete, with self-service keys and rate limiting
  • 18 Togolese localities across all five regions
